# minecraft-6bit-ALU

A simple 6-bit ALU built in Minecraft with the following components:

### Arithmetic
- 6-bit adder
- 6-bit subtractor (built by inverting the second input and adding 1 to the first carry-in)

### Bitwise Logic
- OR, AND, XOR (basic bit-to-bit operators)
- NOR, NAND, XNOR (built with the same model but with inverted output)
